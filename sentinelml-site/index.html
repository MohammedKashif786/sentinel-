    How the models were trained

    The curves and numbers on this page come from the real PyTorch training run on the simulated dataset.

    LSTM autoencoder: loss per epoch

    GNN (GraphSAGE): loss per epoch, log scale

    Training recipe

    1
    Split by time. Windows before 1,500 train, later windows test. The h3 and h4 attacks are never seen in training.
    2
    Learn “normal” per device from normal training windows only.
    3
    LSTM autoencoder: 7,263 normal sequences, rebuilds its input, MSE loss, Adam lr 0.001, batch 128, 25 epochs.
    4
    Risk scale: the 99th percentile of normal errors maps to a low risk, bigger errors approach 100.
    5
    GNN: 1,500 graph snapshots, 2 GraphSAGE layers, cross-entropy with attack class weighted ×8, Adam lr 0.005, 30 epochs.
    6
    Evaluate on the later windows against a fixed threshold and Isolation Forest.

    How the LSTM works

    The LSTM is an autoencoder trained only on normal behaviour. It reads the last 12 time windows of a device, rebuilds what it expects, and the gap between expected and actual becomes the temporal risk. Pick a node:

    1 · Input: last 12 windows (connections per minute)

    Purple = actual traffic, grey = what the model expects for this device.

    2 · LSTM cells read the windows in order, then the decoder rebuilds the sequence

    Each cell keeps a memory (cell state) and uses forget, input and output gates to decide what to keep from earlier windows. Highlight moves along the chain.

    3 · Error becomes temporal risk

    How the GNN works

    The GNN looks at who talks to whom. Each node collects messages from its neighbours, combines them with its own features and decides whether its connections look normal. Pick a node:
